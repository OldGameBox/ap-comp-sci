#java
- **Javadocs** is a specific standard for commenting Java programs, referring to both the documentation tool and the commenting style.
- Purpose: Provides a professional, standardized way to explain code so other developers can easily understand and use it.
- **[[Javadoc comments]]** use a specific syntax and tags to describe methods, parameters, and return values.
- Key components:
    - A description of what the method does.
    - **[[@param]]** tags for each parameter.
    - An **[[@return]]** tag for the value being returned.
