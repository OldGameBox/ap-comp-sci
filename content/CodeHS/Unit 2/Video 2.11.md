#java #control-flow
- [[If statements]] allow code to execute only if a [[boolean]] expression is `true`.
- [[If-Else statements]] provide two branches: one for `true` and one for `false`. Only one branch will ever execute.
- [[Else-If statements]] allow for multiple conditions to be tested in sequence.
    - Only the block for the _first_ `true` condition executes.
    - An optional `else` block can be added at the end to catch cases where none of the conditions were met.
- **Common Pattern**: To check if a number is even, use `if (number % 2 == 0)`. This uses the [[modulus]] operator to see if there is no remainder when divided by 2.
- These structures use [[comparison operators]] and [[logical operators]] within their conditions.
