#java #loops
- [[for loop|For loops]] in Java work the same way as in Karel.
- Structure: `for (int i = 0; i < count; i++) { ... }`
- Breakdown of the loop parts:
    - **Initialization**: `int i = 0` sets the starting value of the counter.
    - **Condition**: `i < count` uses [[comparison operators]] to check if the loop should continue.
    - **Increment**: `i++` uses the [[increment operator]] to update the counter after each iteration.
- A loop starting at `0` and continuing while `i < 3` will execute exactly 3 times (for values 0, 1, and 2).
- You can use [[System.out.println()]] inside the loop to see the current value of the counter `i`.
