#java #loops

- [[while loop|While loops]] allow you to repeat a block of code as long as a [[boolean]] expression remains `true`.
- Structure: `while (boolean expression) { ... }`
- Components:
    - **Initialization**: Declaring a variable before the loop.
    - **Condition**: The [[test]] (boolean expression) checked before each iteration.
    - **Update**: Modifying the variable inside the loop body to eventually make the condition `false`.
- **Infinite Loops**: A common error where the loop condition never becomes `false`, causing the program to hang.
- While loops can use any complex condition with [[comparison operators]] or [[logical operators]].
- Difference from [[for loop]]: While loops are often used when the number of iterations isn't known beforehand, whereas for loops are structured for a specific count.
