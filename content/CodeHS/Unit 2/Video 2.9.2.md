#java #loops #math
- This lesson demonstrates how to use a [[for loop]] to solve a mathematical problem, specifically summing a range of numbers.
- **Key Concepts**:
    - [[constants]] - Variables like `Min` and `Max` used to define the boundaries of the loop.
    - [[accumulator variable]] - Using a variable (e.g., `sum`) declared **outside** the loop to store a running total.
- **The Process**:
    1. Initialize the accumulator (e.g., `int sum = 0;`).
    2. Set up the loop using the counter `i` to represent each number in the range.
    3. Update the accumulator inside the loop (e.g., `sum += i;`).
    4. Print the final result after the loop finishes using [[System.out.println()]].
