#java #input
- Programs become interactive by getting input from the user.
- User input methods require a **prompt** (a string) and return a value that can be stored in a variable.
- **Methods**:
    - [[readLine()]] - used to get text from the user.
    - [[readInt()]] - used to get whole numbers.
    - [[readDouble()]] - used to get decimal numbers.
    - [[readBoolean()]] - used to get true/false values.
- These methods are part of the [[ConsoleProgram]] class in CodeHS.
- You can use [[concatenation]] to combine the input stored in variables with other strings for output.
