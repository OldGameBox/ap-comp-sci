#karel #java
- *Karel* uses `Karel` class with a built-in method `run()` which describes the actions that *Karel* has to perform.
- To adjust `run()` method the architecture asks us to extend `Karel` class into a new public class and then define `run()` within this new class.
- Example:
```java
public class SquareKarel extends Karel {
	public void run()
	{
		// Our code here
	}
}
```
