#java #object-oriented-programming
- [[Object-Oriented Programming (OOP)]] - a programming model focused on objects and the data/actions associated with them.
- [[Class]] - a template or blueprint for creating objects.
- [[Object]] - a structure that contains both **state** and **behavior**.
- **State** - the data about an object (e.g., width, height).
- **Behavior** - the actions an object can perform (e.g., getting area).
- [[new]] - a keyword used to create a new instance of a class.
