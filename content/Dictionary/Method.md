#java #def
- *syn. to **function***.
- (*def.*) a reusable block of code which only runs when it is called.
- [[Naming Conventions#Methods|Naming Conventions - Methods]]
- each **method** in *Java* has 5 items:
	- **[[Modifiers|modifiers]]** - *e.g.* `public`, `protected`, `defualt`
	- **return-type** - declares the type of a variable that a function will return
	- **method-name** - declares a name of a method
	- **parameter-list** - declares a list of parameters a method accepts.
	- **body** - contains the code a method should perform.
